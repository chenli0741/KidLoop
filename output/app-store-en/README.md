# KidLoop — English iPhone screenshots

Four original PNG screenshots captured from the current KidLoop iOS shell on an iPhone 17 Pro Max simulator (iOS 26.4), using the current web UI and an isolated local demo database.

- 01-parent-schedule.png — Parent schedule and pickup status
- 02-driver-trips.png — Assigned driver trips
- 03-today-overview.png — Operations overview
- 04-student-management.png — Student roster

Resolution: 1320 × 2868 pixels, portrait. English app and system locale. Status bar: 9:41, full battery. No production records, real child photos, or contact details are used. Names, locations, and trips are fictional demonstration data.

Upload the four PNG files in App Store Connect under the English localization and iPhone 6.9-inch screenshot section. Do not upload the ZIP or this README.

Apple screenshot specifications: https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/

These captures use a local screenshot-only app configuration. The repository's server URL and production data were not changed. Screenshots have not been uploaded or submitted for review.
