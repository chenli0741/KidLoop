# Pickup / Drop-off 操作位置记录

点击「已接到」、撤销接到、撤销送达、缺席及未接到时，前端发起一次设备定位。点击确认「完成线路」时采集一次，并将同一快照记录在该次实际送达的每名学生的状态历史中，同时保存在车次完成记录。

记录字段为 `operation_location` JSON：定位结果 `status`，成功时含 `latitude`、`longitude`、`accuracyMeters` 和设备采集时间 `capturedAt`。操作者和服务器操作时间继续使用原历史表字段。位置信息由设备提供，仅作为操作记录，不代表后台已验证实际到场。

不做距离判断、围栏、学校地点匹配或定位成功门槛。拒绝定位、设备不可用、不支持、超时（最多等待五秒）、无效数据均保存原因并继续原有接送流程。旧客户端未传位置记 `NOT_PROVIDED`；旧历史保持 NULL，不推断或补造历史坐标。

按操作单次采集，禁止后台持续追踪，不使用缓存定位。不进行地址反查或新增地图跳转。撤销会生成新历史，不覆盖原操作的位置；共享接送并发失败不产生成功记录。

Web 使用浏览器定位；iPhone 壳增加 `NSLocationWhenInUseUsageDescription`。已安装 App 要更新原生包才能包含这项用途说明。实际定位取决于设备权限、系统和连接环境；尚未进行物理 iPhone 实机定位验收。

迁移：028_operation_locations.sql。验证覆盖成功、拒绝、超时、无效数据、跨车并发、批量送达位置、撤销后的历史保留。此版本仅存储审计数据，未新增位置历史查询界面。
