# KidLoop AI 调用日志

项目专用持久日志为 PostgreSQL 的 `reschedule_usage` 表，每次实际调用模型单独记录。线上运行于 Vercel，使用数据库保存日志，避免部署或函数退出造成文件丢失。

## 每条记录

- 唯一日志 ID、关联调整请求 ID、记录时间。
- 文字解析或语音转写、模型、成功或失败状态。
- 模型调用耗时（毫秒），不包含排班算法及页面加载耗时。
- 原始 API 用量，包含接口返回的输入、输出、总 token、缓存和推理明细；推理 token 不重复加到输出上。
- 估算美元费用及当次单价依据。无法取得用量或单价时保留空值，不能当成免费。

每次追加条件、追问后的再次解析以及失败的模型调用均单独留存。缺配置、未发起模型请求的输入校验失败不产生模型调用日志。确认应用使用代码保存排班，不调用模型，不虚增一次 token 记录。

页面在执行结果下方逐条显示耗时、token 用量和费用，默认展开；同时显示输入/输出明细、模型、状态和洛杉矶时间。金额保留六位小数，更小的正数显示小于 $0.000001。失败而没有返回用量时显示“未返回”；无费用依据时显示“待核算”。

## 导出日志

```sh
npm run ai:usage-log -- --date 2026-09-08
```

省略日期则导出洛杉矶当天。命令从 `.env.local` 加载数据库配置，仅运行只读事务，输出 `.local-data/ai-usage-logs/YYYY-MM-DD.jsonl`，每行对应一条调用记录。同日期重新导出会刷新该日期的本地副本，不改数据库日志。导出包含原始用量和计价依据，不含 API 密钥、原始用户指令、学生姓名或接送地址。文件按当前系统用户权限保存，且已被 Git 忽略。

数据库日志是持续记录的原始来源；本地 JSONL 是按需导出的副本，不是 Vercel 文件日志。
