# 共享接送

共享属于学校某次接送批次，统一需求见 [线路与每日接送核对](route-planning.md)。

参与线路按同一学校和放学时段取得同一共享名单。没有主线路或伙伴线路设置，不逐个孩子设置共享。个别另行接送的孩子从本次共享名单取消勾选后仍然显示；安排完整性在每日接送核对中检查。

司机沿用「已接到」，其他车辆同步显示已接走状态及车辆。服务端事务保证一份学生执行记录，保留请假和操作历史。固定学生按行驶路段预留座位，共享候选按实际接到占座。完成整条行程后状态只读。

每辆车的最低、最高共享人数在排班生成时计算并保存，司机执行时不得重新计算，也不得用另一辆车的人数、容量、进度或其他 Stop 状态判断本车能否出发。司机可以逐个 Pickup；本车已接人数位于保存的最低值和最高值之间（含边界）时 GO 可用，低于最低值或高于最高值时 GO 置灰。超过最高值时允许撤销 Pickup 直至回到范围内；车辆物理座位数始终是 Pickup 的硬上限。两辆车执行期间唯一共享的实时事实是每个孩子是否已经被某辆车接走，服务端事务必须保证同一孩子不能被两辆车同时确认。

同步接口必须鉴权，不能因轮询触发生成；断网显示重试，不能离线抢占。同一批次的配置是唯一来源，不能另建独立每日共享设置。
