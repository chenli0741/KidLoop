# 运营学期需求与实施规格

更新：2026-09-07。本文落实本轮语音确认，优先于旧的逐校创建学期、仅存档校历方案。

## 目标与流程

管理公司按运营学期开展业务：新建学期 → 校历初始化 → 核对学生与学校差异 → 规划固定线路 → 日常执行 → 学期结束整体归档。日常只关注本学期、实时和未来任务；归档只供少量历史查询。

本版一个公司同时使用一个工作学期，允许提前创建尚未开始的学期。结束并归档后再建立下一期，不增加同时维护多个规划工作区的复杂度。

## 新建学期

管理员填写名称、开始日期、结束日期；默认地区使用当前业务的美国联邦假日日历（不是宣称所有学校必须放假）。所有已有学校初始化为相同起止日期。新增学校也获得本期日期和假日。

每所学校在当前学期只有一组起止日期；学校页面只能编辑，不能新增或删除学期。学校起止日期可以早于或晚于运营学期，不校验是否落在运营学期范围内。运营学期日期仅用于初始化默认值；各校日期差异在本校修改，不影响其他学校。

系统根据新日期对应的年份重新计算法定假日及周末补休日，生成各学校独立记录。初始化只执行一次，不覆盖管理员后续调整。可以删除某校不放假的默认假日，也可改时间；春假、教师培训等本校特殊日期由管理员逐校录入。

## 沿用上一期

可选择一个已归档学期作为来源：

| 数据 | 新学期处理 |
| --- | --- |
| 学生名单 | 带入待核对名单，保留上期年级班级供参考，必须确认新学期年级和班级；不自动升一级。 |
| 每周年级接送规则 | 复制年级、星期和时间，可局部修改。 |
| 线路站点、顺序、上下车安排 | 复制为未启用草稿。 |
| 司机和车辆绑定 | 不自动绑定，启用前重新选择。 |
| 学期日期、线路有效日期 | 使用本次输入的新日期，不沿用旧日期。 |
| 默认假日 | 依新日期重新生成，不复制旧年假日。 |
| 春假、其他具体特殊日期 | 不复制，由管理者重新填写。 |
| 已执行任务、请假留言、状态历史 | 留在原学期，不复制。 |

复制草稿不能自动生成任务；核对学生、站点、时间、司机车辆后再启用。可以不复制，选择已有学生加入本期或新增学生。

## 日常执行与特殊日期

沿用既有固定线路自动任务、日期例外和冲突提示。可设置一天或一周全校特殊放学时间，覆盖平时规则，结束后恢复。保留现有冲突提示，不新增逐条线路确认工作流。

今天、司机、家长和学生名单只显示未归档工作学期的数据；无工作学期时，显示清晰的空状态和管理员新建学期入口。学校、课外班、司机、车辆、账号是长期基础资料，不清空。

## 学期归档

管理员在学期结束后明确执行“归档本学期”，看到日期、范围和确认提示；不自动删除数据，不在本次功能上线时自动归档现有学期。尚未完成的历史任务按原状态归档，不强制逐条补操作，也不自动改成已完成。

归档包含学校日期、假日、年级规则、固定线路、学生参与关系、行程、学生状态和请假留言。保存冻结快照，后续新学期学生升班、基础资料更名不改变旧档案。归档页只读，不提供恢复到当前或在旧数据上编辑。

归档后停止该学期任务生成，主工作界面不再显示旧计划和旧学生名单。基础资料保留；新建学期默认空计划，可选择复制一个已归档学期。旧请求必须被服务端拒绝，不能误改下一期。

## 迁移与验证

上线迁移把当前已有日期和配置纳入一个工作学期，不更改已确认学校日期、不立即取消线路或归档真实数据。历史无学期的旧行程通过日期关系纳入现有学期，保留执行记录。

验证包括：初始化日期和假日、学校日期只能编辑、学校例外互不影响、复制不携带日期和状态、待核对学生阻止启用、归档后所有日常入口为空、历史快照不受新修改影响、重复提交及旧表单隔离。

默认联邦假日参考 [OPM 官方日历](https://www.opm.gov/policy-data-oversight/pay-leave/federal-holidays/)，仅作为各校可修改的初始化模板。

## 页面与权限

- 管理员的今日、学校、线路、学生页面提供紧凑的当前学期条和“学期管理”入口，Web 与 iPhone 共用业务规则，布局自适应。
- 学期管理集中提供初始化、学生核对、期末归档和历史查询；学校页面不再提供新增、删除或单独归档学期。
- 司机只执行本期任务；家长只看到孩子本期资料与安排。学期管理及历史归档仅管理员可访问。
- 整体归档后，日常页面显示新建学期入口，不显示上一期名单或任务；历史入口收起，避免占用日常操作空间。
- 复制后的学生核对须包含当前年级、班级、目的地；线路仍支持同校多个目的地、多学校多站点及固定司机车辆。
